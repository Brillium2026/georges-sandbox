# George's Sandbox

The FirstBreath free-floating sandbox — one page, no install, no account.
Steven built the platform; this little room is yours.

**Open it:** https://brillium2026.github.io/georges-sandbox/
On your phone, use "Add to Home Screen" and it sits there like an app.
It works offline once loaded.

## What you're holding

A design surface that cannot lie to a 3D printer. Millimetres, Z up.
Every part is a true solid; the page validates watertight before it
will export, and the **Export STL** button is the printer file.

- **INSPECT** — geometry locked. Orbit, zoom, change colours and light
  all day; none of it can move a vertex. The geometry hash proves it.
- **EDIT** — the deliberate unlock. Change sizes and positions; every
  change revalidates live.
- **The inner sandbox panel** — measure the object the robot arm can't
  handle, tap "Design a collar for it" or "Design a gripper for it",
  and the sandbox sizes the part, shows its reasoning, and loads it
  ready to export.

It opens on the SO-101 grip kit: a mounting plate, a tool collar, and
four flexure fingers — fingers with a thin neck that bends, so the
grip yields at contact instead of shoving through it.

Friday's loop, five beats: **fail → read → design → print → succeed.**

Built from the FirstBreath sandbox heart — the same geometry that
runs inside the platform, verified part for part.
